# STM32F401 Motor Control with PWM

Проект управления DC мотором через PWM на микроконтроллере STM32F401.

## Описание

Программа управляет DC мотором с помощью двух кнопок:
- Кнопка 1 — мотор вперёд
- Кнопка 2 — мотор назад
- Кнопки не нажаты — мотор останавливается

Скорость мотора задаётся через PWM (TIM1, канал CH2).

## Железо

| Компонент       | Описание                     |
|-----------------|------------------------------|
| MCU             | STM32F401xC                  |
| Таймер          | TIM1 — генерация PWM         |
| GPIO выходы     | PA0, PA1 — направление мотора |
| GPIO входы      | PA2, PA3 — кнопки (pull-up)  |
| PWM выход       | PA9 (TIM1 CH2, AF1)          |

## Подключение

```
PA0  --> IN1 мотор драйвера (направление)
PA1  --> IN2 мотор драйвера (направление)
PA9  --> ENA мотор драйвера (PWM скорость)
PA2  --> Кнопка "Вперёд" (подтяжка к VCC, нажатие замыкает на GND)
PA3  --> Кнопка "Назад"  (подтяжка к VCC, нажатие замыкает на GND)
```

## Настройки PWM

| Параметр    | Значение                        |
|-------------|---------------------------------|
| Частота PWM | 1 кГц                           |
| Prescaler   | 83 (при 84 МГц тактирование)    |
| ARR         | 999                             |
| Duty cycle  | 0 — 999 (0% — 100%)            |
